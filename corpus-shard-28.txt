Gifts

Four small tools, pulled out of the working system and given away. They carry no methodology, they stand on their own, and they're released under the MIT license — use them in anything, including something you sell. No attribution required, though it's always kind.

Each one ships with its limits printed on it — because a tool that hides its edges is the opposite of a gift.

grain — a structure-vs-random smell test

Compress your data with a stdlib compressor, compare the ratio against a size-matched, deterministically-seeded random null model drawn live, and read back how much structure vs. noise — no hand-set threshold. Snapshot it over time and it becomes a cheap drift alarm for a corpus going stale or homogenizing.

Honest edge: it's a smell , not a proof. Great for staleness and homogenization drift; a smoke alarm, not an arson investigator. Not a data-rot / dead-link checker. Python stdlib only.

cairn — self-healing multi-store git redundancy

Priority-ordered failover clone, a host-aware credential helper, and redundant push across distinct-class git stores, so your canonical history survives any one store going away. The load-bearing idea is the independence class : two mirrors on the same provider aren't redundancy. Describe your stores once; a push succeeds only when enough distinct classes confirm it.

Honest edge: it survives store loss, not corruption you push yourself — push a bad commit and every mirror faithfully keeps your mistake. Bash + git. Ships with an example config carrying no real hosts or credentials.

plumb — a status board that refuses to go green on hope

A tiny audit pattern for anyone whose dashboards turn green on intention instead of evidence . Each claim names a witness — a file that must exist, text that must be present, a command that must pass — and the claim renders green only if its witness actually agrees. Assert done with nothing beneath it and you get UNWITNESSED , not a pass.

Honest edge: it checks the witness exists and agrees , never that the witness is the right one. Point it at the wrong file and it'll happily pass — choosing a meaningful witness is your job. Python stdlib only.

ward — a status badge that won't go solid on hope

The badge-shaped sibling of plumb. A grid of cells, one per claim, each naming a witness — a file that must exist, text that must be present, a command that must pass. A cell renders solid only when its witness actually agrees; anything missing, disagreeing, or malformed renders as a hollow ring , never a silent solid. Drop the HTML fragment in a page or the glyph grid in a README and the badge is wired to real evidence, not to whoever last edited the markup.

Honest edge: like plumb, it checks the witness exists and agrees , never that it's the right witness — presence is not proof of substance. A cmd: witness runs your shell, so treat a spec like a Makefile. Python stdlib only.
