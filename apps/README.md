# Apps

Selected apps built with Loop MMT, published here as browsable source. Some run
in your browser; others are read-the-code because they need a server or a local
runtime. Each app has its own README with the details.

| App | What it is | How to use it |
|---|---|---|
| [**loop21**](loop21/) | An 18,000-line flow computer that runs entirely in one HTML file — zero dependencies. | [Run it in your browser](https://loopmmt.com/apps/loop21/loop21-build333.html) · read the code. |
| [**butcher-constellation**](butcher-constellation/) | A single-file order-management system for a seasonal deer processor. | Read the code — a Node app; clone & run locally. |
| [**battleganza**](battleganza/) | Sudoku smashed into Tic-Tac-Toe, head to head — a Forest-native multiplayer game. | [Run the standalone](https://loopmmt.com/apps/battleganza/battleganza-standalone.html) (hotseat) · read the code. |
| [**beam-wizards**](beam-wizards/) | A 3D-optics puzzle: steer light through a cube of mirrors and lenses. | [Run it in your browser](https://loopmmt.com/apps/beam-wizards/beam-wizards.html) · read the code. |
| [**jamies-garden**](jamies-garden/) | A falling-block game built as a gift; installs to the home screen like any app. | [Run it in your browser](https://loopmmt.com/apps/jamies-garden/) · read the code. |
| [**loop-sudoku**](loop-sudoku/) | A self-certifying Sudoku solver core that reasons one logical step at a time and shows its working. | Read the code — solver core, no hosted play yet. |
| [**forest**](forest/) | One app for your own data — email, calendar, and contacts in a single shell. | Read the code — a hosted platform; runs through a server-side runtime, not statically. |

The polished, illustrated version of this list — with screenshots and the story
behind each app — lives on the site: **[loopmmt.com/apps](https://loopmmt.com/site/apps.html)**.
