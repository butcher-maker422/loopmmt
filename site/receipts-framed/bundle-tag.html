The Bundle Tag

The Receipts

Artifact
the Bundle Tag
Kind
session close cover sheet
Authored by
an AI system (site context prose)

When a Loop MMT session closes, it does not hand you a scatter of files to go and collect. It writes one cover sheet — the Bundle Tag — and packs everything the session produced into a single download beside it. The tag is the manifest: what is in the bundle, and where each piece came from.

Read it as a packing slip. It names the five-face closing mesh (the handoff, the status report, the chaos report, the room report, and the note-taker’s notes), the small state sidecar the next session reads first, any artifacts the session built, and the key commits that carry the work in the repository. The manifest is folded from the session’s own branch, not typed by hand, so it cannot quietly omit a file that was actually committed.

That is the point of banding a session: the record leaves in one piece, or the close fails loudly. A session that could drop a file on the way out is a session whose record you cannot trust. The Bundle Tag below is a real one, from an actual session close.
