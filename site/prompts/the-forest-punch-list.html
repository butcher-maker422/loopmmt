The Forest Punch List

Assemble It All, Then Work It In Blocks

Short and operational — put it on the list and work it:

The Prompt

Can you please assemble everything that needs to be done for the Forest- everything you turned up here- onto the Punch List, if they are not already, and then start working it so we can get them all done? That is what I would like you to do. Plan it smartly, think in blocks, and bake in strongly mechanisms so that you are using all your available context- you want to be doing all the fruitful work in a session that you can and then filling the Cistern at the end with any spare drops of context before running a good handoff and picking up the work on a fresh tank after the handoff. It's a pretty basic pattern--> DO GOOD WORK THAT FITS->FILL THE CISTERN WITH SPARE CONTEXT->RUN GOOD HANDOFF> PICKUP WORK ON FRESH TANK IN NEXT SESSION AFTER LOADING IN PROPERLY. Rinse and repeat.

— Shea Gunther · operator drop, 10.2006

The Anatomy

“assemble everything that needs to be done for the Forest … onto the Punch List … and then start working it” — The two moves in order: gather the scattered work into one inspected list, then work it — the Punch List is both the register and the thing that says when a line is genuinely done.

“think in blocks, and bake in strongly mechanisms so that you are using all your available context” — Block-sized work plus context discipline: size each unit to fit a session and build the rhythm in, rather than relying on remembering to stop at the right place.
