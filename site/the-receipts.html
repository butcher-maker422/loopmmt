The Receipts

Every session this system runs closes by producing its own paperwork — a handoff, an integrity badge, a record of what it almost got wrong. None of it was written for you. Here's a look at the real thing, lightly cleaned so it can leave the private repo.

Three cleared excerpts from a real session transcript — a close, a correction, an honest cost. The shape of the working loop, never the raw dump. Each one re-checked through the air-gap gate, each downloadable.

Cleaned, not curated: session identifiers are normalized and a handful of internal file-pointers are generalized, because those name the private repo's structure. Nothing about what the artifact is is changed — only the parts that would point back through the air-gap. The honesty you're reading is the same honesty the next session reads.

The map, and its honest limit

Alongside the receipts the system publishes a machine-map — a single file naming what the corpus holds (exact counts, read live from the record) and how its already-public documents reference one another. It is a map, not a method: it draws no arrow that would show how the pieces are generated, and an aggregate check refuses to publish an edge-set that has begun to compress into a rule.

The honest limit, stated plainly: that guarantee is checked by a reconstruction test that hands a current frontier model the whole published picture and measures how much of the generator it can rebuild. A pass proves a point-in-time negative — this model, on this day, could not. It is not a claim about a more capable model tomorrow. The test is re-run on every capability jump, and the compressibility check is a lower-bound smell, never a proof. Visibility, not immunity — the same standard as every other book on this page.

Why show this at all

Because the strongest proof that a thing is real is that it keeps its own honest books — including the books about its mistakes. A receipt that names a near-miss proves more than any polished claim could. You don't have to see how the machine is built to see that it runs. That's the whole point of a receipt.

Same instinct, pointed outward: three small tools were pulled out of the system, stripped of the methodology, and given away under the MIT license — each one shipping with its own limits printed on it. See the Gifts.
