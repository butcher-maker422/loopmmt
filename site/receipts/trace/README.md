# The byte-truth trace — a curated bundle

Three cleared excerpts from a real design-session transcript, each showing one
shape of the working loop:

1. **A close** (`excerpt-1-a-close.txt`) — the system files its own record and
   verifies it against what actually landed.
2. **A correction** (`excerpt-2-a-correction.txt`) — the system proves the
   operator's proposal wrong with arithmetic, then fixes it.
3. **An honest cost** (`excerpt-3-an-honest-cost.txt`) — the system names the new
   risk its own good decision created, and ranks it.

**What this is not.** It is not the raw transcript. The raw session logs carry
internal paths, tool names, and session mechanics wholesale — they never leave the
private repo. These excerpts are curated: trimmed to the shape, cleaned of every
private signature, and each one re-gated through the air-gap check. They show
*that* the loop runs and *how it behaves*, never *how the machine is built*.

Every file in this bundle passes the air-gap gate at zero signatures.
