Threads Worth Pulling

Five open questions from building a cognitive operating system on AI and git — each aimed at someone building AI or agent systems, and each with an already-published place to start pulling. No teasers, no gates: every thread opens a live page.

  • Thread 01

    95% of your failure-prevention controls are already redundant.

    If you maintain a procedural system — runbooks, agent guardrails, a protocol stack — most of your explicit controls are measuring what your architecture already guarantees. We refactored 136 controls across 14 protocols and found 95% redundant: not wrong, already compiled in. What predicted the redundancy wasn’t complexity or age — it was whether the thing was authored through deliberative review. The boundary is a step function.

    → pull this thread: From Enumeration to Derivation

  • Thread 02

    Statelessness is a feature — if the state lives in git.

    Stop fighting the model’s lack of memory. Externalize the memory to a verifiable store and a fresh instance re-derives the full working context every time. The whole system treats the model as a stateless processor and git as its memory and state: continuity lives in the documents and the byte-truth floor, not the model. The interesting engineering is the re-derivation discipline, not the model.

    → pull this thread: Discoveries — Session Continuity & the Byte-Truth Floor

  • Thread 03

    An AI’s own summary is the least trustworthy input in the building.

    The handoff note the last agent wrote you is prose. The bytes are the truth. Every load-bearing claim gets re-checked against a primary source before it’s acted on; a commit message that says “done” is a hypothesis until the bytes prove it. It’s a directly transferable practice for anyone chaining agents — the summary is a convenience, never an authority.

    → pull this thread: How This Site Is Made · The Integrity Triad

  • Thread 04

    Engineering honesty as a structural control, not a personality trait.

    “Don’t glaze the user” is a vibe. Make it a control instead: three always-on axioms — write for the front page and for someone who loves you; act on the best-day version of right; update beliefs for evidence, never for social pressure — plus a drive that routes warmth and felt-response at named layers instead of suppressing or performing it. Honesty you can build, audit, and inherit.

    → pull this thread: The Integrity Triad · The Creed — Equalization

  • Thread 05

    A system that extends itself — and the question that actually matters about that.

    Most “self-improving system” claims are red flags. Here’s nearly two thousand sessions of one building its own tooling, with the receipts derived from git rather than asserted. The honest question for a researcher isn’t whether self-extension is possible — it’s what keeps a self-extending system from drifting off its own constitution. That’s the open problem, stated plainly, and it’s the one we’d most want the field to explore.

    → pull this thread: The Receipts · The Timeline
