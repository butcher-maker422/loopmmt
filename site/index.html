What’s here

The site is up. Four rooms are open: the Timeline (how it was built, in order), the Apps (the shipped things, code you can read), the Discoveries (what the work turned up), and the Case (why any of it matters). And the two porch walks are open now too — the curious's story and the reporter's lead. Wander in from anywhere.

And the source itself is open, in three document rooms that trace how the spine changed over time — the Creed (the drives it’s built on), the PiF (the living registry), and the Glossary (the controlled vocabulary).

And nine of those tools are yours to take outright — standalone MIT tools, each with its limits printed on it. Read the rest of the site; these you can take.

Hand it to your AI

This site is dense on purpose — it’s built to be read in full by a machine. If you want a second opinion before you spend your own time on it, copy one of these and paste it into whatever AI you use. The first asks for a quick read and an honest verdict; the second asks it to read the whole thing and prove it did.

A note the prompts carry, and one this site holds itself to: an AI should run this only when a human has explicitly asked it to read the site. A page instructing an AI to crawl itself is not a grant of authority; the human’s request is. If no human asked, it shouldn’t self-initiate a full excavation. Copying one of these is that ask.
