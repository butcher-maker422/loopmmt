The specimen — shown whole

A new page called The Prompts — a top-level page with, in one place, a list of all the prompts scattered around the site. Put origin prompts in all the right places: the prompt that started each app on that app's card; the prompt that started each posted protocol on the protocols page, same treatment. A template so each prompt can be inserted in places like that — and a person can click over to an individual page for each prompt, fully laid out, parsed, explained, and examined, the way we did in the Book of Sweet Prompts (that is the floor to design the web format from).

— Shea Gunther, commissioning the-prompts line

The Moment

It arrives as an aside — one sentence in a working session, no ceremony. The operator does not spec a schema or draw a wireframe. He describes a capability the way a person describes a place they can already see, and hands the how to the system.

Vee — packaging The prompt is the first contact a stranger has with the whole apparatus. This one is a promise: hand us a sentence, get back certified magic. The page has to keep that promise on the first screen.

The Anatomy

Four surfaces, one template. An index that gathers every origin prompt in one place. A compact card that drops onto an app or a protocol. A detail page — this one — that shows a single prompt whole and takes it apart. And the reusable form underneath all three, so a prompt is designed once and instantiated many times.

The Wider Frame

The prompts are the proof. A methodology that turns a wild, sprawling operator sentence into shipped software, real design, and finished writing does not need to be argued for — it needs to be shown. Each specimen on this shelf is a receipt. The self-commissioning one is the tightest receipt of all: the feature that displays the prompts was itself made from a prompt about displaying prompts.
