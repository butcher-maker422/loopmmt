Shruting Something Up

The prompt that taught the system a word for its own mistakes.

Not every prompt builds an app. This one edited the methodology's own vocabulary mid-flight. In a single message the operator coined a term — to Shrute something is to mess it up — and bound it to a mechanism the system already had: a Glorp, the correction reflex that fires when the operator flags a mistake. From then on, "you Shruted Thing X" is the signal to Glorp Thing X.

The same message did two more things at once. It caught a live packaging defect — the session's handoff bundle hadn't been assembled to the standard — and it set a standing rule for a system still settling: register corrections now, but don't auto-fix them until told to revert to default. The ask, "work that into wherever it needs to be worked into the system," landed as a named convention rather than a one-off note.

If You Shrute It, You Glorp It

Hey, new thing- if you "Shrute" something up, it means you messed up and it needs a Glorp. So I ever point out that you "Shruted" Thing X, you should then Glorp Thing X. Can you please work that into wherever it needs to be worked into the system? And can you then kick me out a short report on all the things you did to which file to add that in? Also, you did NOT package up the hand off docs right- where is the Bundle Tag doc and all files from the session? There is a format- look it up, don't just make it up. Don't worry about trying to fix up the handoff document thing right now- we're kind of settling a chaotic system so I'm ok with not fixing things the moment they break. You can just register stuff right now, you don't need to autofix Glorps until I tell you to revert to default behavior.

— Shea Gunther · the operator building the language he corrects you in

The Anatomy

The prompt does three things at once. It coins a term — "Shrute" — for a category the system needed a handle on (the operator-flagged mistake). It binds that term to a mechanism that already exists — the Glorp — so no new machinery is built, only a new trigger for old machinery. And it catches a live defect in the same message: "where is the Bundle Tag doc and all files from the session?" — a packaging miss flagged the moment it is noticed.

The deeper move is a policy, not a term: "you can just register stuff right now, you don't need to autofix Glorps until I tell you to revert." An operator settling a chaotic system deliberately chooses detection over correction — log the fault, hold the fix — so the system stops thrashing on every break. That single sentence is a whole operating mode, stated as an aside.
