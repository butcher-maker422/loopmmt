Find the tool by what it does.

One honest rank over every single-file gift in the cabinet. An empty query browses them all; type and it ranks. The rank is computed at query time — nothing is pre-sorted to sell you a tool.

The chips below narrow to the gifts already classified by where they sit in a pipeline — source, transform, filter, fold, sink. A chip filters the set; it never re-ranks it. Text search always covers every gift, classified or not.
